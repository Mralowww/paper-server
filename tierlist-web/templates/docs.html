使用說明 / API 文件

給玩家看的綁定流程,以及給 Mod / 第三方開發者用的公開 API。

玩家:如何綁定 Minecraft 帳號

  1. 到用 Discord 登入
  2. 登入後在我的帳號頁面會看到一組驗證碼
  3. 到 Minecraft 伺服器輸入 /verify <驗證碼>,驗證碼 10 分鐘內有效
  4. 綁定完成後就可以在 Discord 按「🎫 申請測試」排隊測 Tier

公開 API

需要先請網站管理員在後台核發一組 API Key,每次請求帶在 Header 或 query string 裡。

X-API-Key: <你的 key> 或 ?api_key=<你的 key>

查詢單一玩家 Tier

GET /api/v1/tier/<mc使用者名稱>

{
  "username": "Steve",
  "uuid": "...",
  "tier": "HT2",
  "region": "TW",
  "ranked": true
}

找不到或尚未評級的玩家會回傳 "ranked": false,tier 是 null。

列出全部排名

GET /api/v1/tiers

[
  {"username": "Steve", "uuid": "...", "tier": "HT2", "region": "TW"}
]

查詢玩家綁定關係

GET /api/v1/player/discord/<discord_id>

GET /api/v1/player/uuid/<mc_uuid>

{
  "discord_id": "...", "discord_username": "...", "mc_uuid": "...", "mc_username": "Steve",
  "tier": "HT2", "region": "TW", "last_test_at": 1234567890
}

找不到會回傳 404 {"error": "not_found"}。

查詢冷卻狀態

GET /api/v1/cooldown/<mc使用者名稱>

{"username": "Steve", "can_test": false, "remaining_seconds": 2591000, "next_test_type": "advanced"}

next_test_type 是依玩家目前段位判斷下一次要考普通(normal)還是高階(advanced)測試。 查無此人一律回傳可以測試。

Discord 控制:發送公告

POST /api/v1/discord/announce

一定要用 scope=control 的 API Key(在後台建立時選), read 權限的 key 呼叫會被拒絕(401)。 

{"channel_id": "123456789012345678", "message": "要發的內容"}

成功回 202 {"ok": true, "queued_id": ...},表示已排進佇列,幾秒內由 bot 實際送出。

查詢測試紀錄

GET /api/v1/tests?username=<可省略>&limit=<可省略,預設 50,最多 200>

不帶 username 會回傳全站最近的測試紀錄;帶了就只回傳該玩家的紀錄。

[
  {
    "username": "Steve", "uuid": "...", "region": "TW", "game_name": "Sumo",
    "score_wins": 3, "score_losses": 0, "tier_before": null, "tier_after": "HT3",
    "test_type": "normal", "examiner": "examiner#0001", "created_at": 1234567890
  }
]
