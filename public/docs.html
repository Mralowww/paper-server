驗證速率限制統計模式與 Tier 排行榜玩家查詢錯誤碼範例程式
Developer API · v1

開發者 API

透過 REST API 讀取 Mc.Tierlist.Asia 的排行榜與玩家資料。所有回應皆為 JSON，Base URL 為 /api/v1。

驗證

每個請求都必須附上 API Key。請聯絡管理員申請，Key 只會在建立時顯示一次，請妥善保存，不要公開在前端程式碼中。

HTTP Header
X-API-Key: mctl_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

也可以使用 Authorization: Bearer <key>。

速率限制

每把 Key 每分鐘最多 60 次請求。回應標頭會包含：

Header說明
X-RateLimit-Limit每分鐘上限
X-RateLimit-Remaining本分鐘剩餘次數
X-RateLimit-Reset重置時間（Unix 秒）

統計

GET/api/v1/stats網站整體統計
Response
{ "players": 128, "tier1": 6, "tier2": 14, "regions": 1, "modes": 1 }

模式與 Tier

GET/api/v1/modes可用模式、Tier 積分表與地區代碼
Tier積分Tier積分
HT160LT145
HT230LT220
HT310LT36
HT44LT43
HT52LT51

排行榜

GET/api/v1/rankings/vanilla依積分排序的玩家列表
參數說明
limit每頁筆數，1–100，預設 50
offset略過筆數，預設 0
region地區代碼，目前只有 TW（台灣）
tier精確 Tier（HT1）或 Tier 群組（1 = HT1 + LT1）
search玩家名稱關鍵字
Response
{
  "mode": "vanilla",
  "total": 1, "limit": 50, "offset": 0,
  "players": [
    {
      "rank": 1,
      "name": "Steve",
      "uuid": "8667ba71-b85a-4004-af54-457a9734eed7",
      "region": "TW",
      "points": 60,
      "title": "Combat Specialist",
      "tiers": { "vanilla": { "tier": "HT1", "points": 60, "retired": false } },
      "updatedAt": "2026-09-25T08:00:00.000Z"
    }
  ]
}
GET/api/v1/players同上（Vanilla 排行榜的別名）

玩家查詢

GET/api/v1/players/{name 或 uuid}單一玩家資料（不分大小寫）

回應格式與排行榜中的單一玩家物件相同；找不到時回傳 404 player_not_found。

錯誤碼

狀態error說明
401missing_api_key沒有附上 API Key
401invalid_api_keyKey 錯誤或已被停用
400invalid_region地區代碼錯誤
404player_not_found找不到玩家
429rate_limited超過速率限制，請依 Retry-After 等待

範例程式

cURL

bash
curl -H "X-API-Key: YOUR_KEY" \
  "/api/v1/rankings/vanilla?limit=10"

JavaScript (Node.js / Discord Bot)

javascript
const res = await fetch('/api/v1/players/Steve', {
  headers: { 'X-API-Key': process.env.MCTL_API_KEY },
});
const player = await res.json();
console.log(player.name, player.tiers.vanilla.tier); // Steve HT1

Python

python
import os, requests

r = requests.get(
    "/api/v1/rankings/vanilla",
    headers={"X-API-Key": os.environ["MCTL_API_KEY"]},
    params={"region": "TW", "limit": 10},
)
for p in r.json()["players"]:
    print(p["rank"], p["name"], p["tiers"]["vanilla"]["tier"])
請勿在瀏覽器前端直接使用 API Key，否則任何人都能看到並濫用你的 Key。請從你自己的伺服器或 Bot 呼叫 API。
